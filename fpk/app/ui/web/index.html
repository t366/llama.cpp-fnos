引擎设置

选项来自「模型」页扫描结果；也可在下方直接填写路径
GGUF 文件绝对路径；也可填仅含一个 GGUF 的目录（自动选用），含多个时需指定文件
OpenAI 兼容 API 监听端口（默认 8080）
0 = 交由 llama.cpp 自动选择
--n-gpu-layers；CPU 变体保持 0，加速变体按显存设置
启用后局域网调用需携带此 Key，可防止局域网滥用
模型扫描根目录，可指向飞牛共享文件夹（M3 生效）
加速变体 tar.gz 资产来源；内网环境选 Gitea 镜像更快
Gitea 仓库 base（release 资产路径与 GitHub 同构）；仅下载源为 gitea 时生效
修改端口/参数后，需重启引擎生效。
